# Font requirements

The archived site CSS and public HTML reference `freight-display-pro` and `freight-sans-pro`, loaded through a Squarespace-generated `use.typekit.net` script. Font binaries were not downloaded.

| Family | Observed use | Weights/styles to inspect in the new project |
| --- | --- | --- |
| Freight Display Pro | Site title, navigation, headings, post titles | Light 300 and Medium 500; italics where the content uses emphasis |
| Freight Sans Pro | Body, metadata, small uppercase headings, buttons | Regular 400, Medium 500, bold and italics used by the content |

These are the main source declarations; final loaded faces and synthesized bold/italic behavior still require browser verification. Use the family names generated by the new provider's embed code if they differ from the old CSS names.

## Independent setup

Recommended: create a web project in the site owner's Adobe Fonts account containing the required Freight families and weights, then use that project's embed code in the Eleventy layout. Availability and the account's active entitlement need to be checked before launch. No account or subscription was inspected or changed in this task.

For fully local assets, obtain a separate self-hosted webfont license from the foundry or an authorized reseller. Adobe's hosted webfont license does not provide local hosting rights. See [Adobe's webfont licensing FAQ](https://helpx.adobe.com/in/fonts/web/font-licensing/webfont-licensing.html).

Squarespace's built-in licensed fonts should not be carried over as downloaded font files; its [licensed-content guidance](https://support.squarespace.com/hc/en-us/articles/360056779311-Licensed-content) limits their use outside its services.
